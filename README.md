# FileSearchAdmin

Административный функционал приложения [FileSearch](https://github.com/Oakey12/FileSearch).

Десктоп-утилита администрирования 1С на Wails v2 (порт 1Cproc). Развёртывание через Nginx — [docs/DEPLOY-NGINX-CICD.md](docs/DEPLOY-NGINX-CICD.md).

## Проверка программы по списку компьютеров

Вкладка **Программы → Проверка по списку компьютеров**:

1. **Загрузить список ПК (JSON)…** — файл со списком компьютеров (IP или DNS-имена).
   Без файла проверяются серверы, отмеченные в карточке подключения.
2. Впишите название программы (`TrueConf`, `1cv8.exe`, первые буквы названия)
   и нажмите **Проверить** (или Enter). Нужны логин и пароль администратора.
3. Таблица заполняется по мере ответа: **Установлена** (название, версия и у
   кого стоит), **Не установлена**, **Ошибка** (ПК выключен, нет доступа и т.п.).
   Фильтр по статусу, **Копировать таблицу** — вставляется в Excel по столбцам.

Одновременно проверяются 8 компьютеров. Ищется так же, как в одиночном поиске:
записи деинсталляции в реестре (общие и загруженных профилей), запущенные
процессы и `.exe` в Program Files, ProgramData и AppData профилей. Если у ПК есть
профили без активного сеанса, их личные установки не видны — это пишется в
«Подробностях», чтобы «не найдено» не путали с «нет».

### Формат JSON

Образец — [`docs/computers.example.json`](docs/computers.example.json), его же
сохраняет кнопка **Сохранить образец JSON…**:

```json
{
  "computers": [
    { "name": "Бухгалтерия — Иванова", "ip": "192.168.20.101" },
    { "name": "Склад", "ip": "192.168.20.120" },
    { "name": "", "ip": "192.168.20.130" }
  ]
}
```

- `name` необязателен — без него в таблице показывается адрес.
- Для длинных списков можно писать только адреса:
  `{"computers": ["192.168.20.101", "192.168.20.102"]}` или просто
  `["192.168.20.101", "192.168.20.102"]`.
- Подходит и `servers.json` с Nginx (ключ `servers`).
- Адреса не должны повторяться; не больше 5000 записей. Ошибка в файле
  показывается с номером записи.

# FileSearchAdmin

Административный функционал приложения [FileSearch](https://github.com/Oakey12/FileSearch).

Десктоп-утилита администрирования 1С на Wails v2 (порт 1Cproc). Развёртывание через Nginx — [docs/DEPLOY-NGINX-CICD.md](docs/DEPLOY-NGINX-CICD.md).

## Установлена ли программа на одном компьютере

**Программы → Программы на компьютере**: IP в карточке подключения, название в
поле (`dr.web`, `TrueConf`, `1cv8.exe`) и **Проверить на ПК** (или Enter). Ответ:

- **Установлена** — найдена запись в реестре, служба или запущенный процесс;
  ниже список находок (где, что, у кого, путь);
- **Только файлы** — есть лишь папка установки или `.exe`, без реестра, службы
  и процесса: похоже на остатки после удаления;
- **Не установлена** — ничего не найдено (с оговоркой, если часть профилей не
  видна: их личные установки читаются только при активном сеансе);
- **Ошибка** — компьютер не ответил, нет доступа и т.п.

Имена сравниваются без регистра, пробелов и точек: `dr.web` находит
«Dr.Web Security Space», папку `DrWeb` и службы Dr.Web. Коды продуктов (GUID) не
сравниваются, а по путям и папкам ищутся запросы от 3 символов — так короткое
«1c» не находит «…0FF1CE» в кодах Office. **Сканировать программы** по-прежнему
показывает весь список из реестра; поле поиска его фильтрует.
## Проверка программы по списку компьютеров

Вкладка **Программы → Проверка по списку компьютеров**:

1. **Загрузить JSON…** — файл со списком компьютеров (IP или DNS-имена).
   Без файла проверяются серверы, отмеченные в карточке подключения.
2. Впишите название программы (`TrueConf`, `1cv8.exe`, первые буквы названия)
   и нажмите **Проверить** (или Enter). Нужны логин и пароль администратора.
3. Таблица заполняется по мере ответа: **Установлена** (название, версия и у
   кого стоит), **Не установлена**, **Ошибка** (ПК выключен, нет доступа и т.п.).
   Фильтр по статусу, **Копировать таблицу** — вставляется в Excel по столбцам.

Одновременно проверяются 8 компьютеров. Ищется так же, как в одиночном поиске:
записи деинсталляции в реестре (общие и загруженных профилей), запущенные
процессы и `.exe` в Program Files, ProgramData и AppData профилей. Если у ПК есть
профили без активного сеанса, их личные установки не видны — это пишется в
«Подробностях», чтобы «не найдено» не путали с «нет».

### Формат JSON

Образец — [`docs/computers.example.json`](docs/computers.example.json), его же
сохраняет кнопка **Сохранить образец JSON…**:

```json
{
  "computers": [
    { "name": "Бухгалтерия — Иванова", "ip": "192.168.20.101" },
    { "name": "Склад", "ip": "192.168.20.120" },
    { "name": "", "ip": "192.168.20.130" }
  ]
}
```

- `name` необязателен — без него в таблице показывается адрес.
- Для длинных списков можно писать только адреса:
  `{"computers": ["192.168.20.101", "192.168.20.102"]}` или просто
  `["192.168.20.101", "192.168.20.102"]`.
- Подходит и `servers.json` с Nginx (ключ `servers`).
- Повторяющиеся адреса пропускаются (проверяются один раз), их число
  показывается при загрузке. Не больше 5000 записей; ошибка в файле
  показывается с номером записи.
- Следующий список загружается той же кнопкой — он заменяет прежний.

## О системе: подключения по RDP

В **О системе → Собрать сведения** есть поле **«Подключения по RDP (14 дн.)»** —
кто и откуда заходил на компьютер по удалённому рабочему столу. Одна строка на
пару «учётная запись — адрес клиента»:

```
SANTEAM\1118 с 192.168.150.202 (LOGINOVA-N) — последнее 22.10.2026 13:49, подключений: 3
```

Данные берутся из журналов Windows на целевом компьютере (аудит включать не
нужно): `Microsoft-Windows-TerminalServices-LocalSessionManager/Operational`,
события 21 (вход) и 25 (переподключение); если он пуст —
`…RemoteConnectionManager/Operational`, событие 1149. Входы за консолью
(`LOCAL`) не показываются. Имя ПК клиента — обратным DNS-запросом (до 10 с на
весь список); без записи в DNS остаётся только IP. Если пользователь заходит
через терминальный сервер, клиентом будет этот сервер.
